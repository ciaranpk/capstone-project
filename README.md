Anime Explorer

Project Description

Anime Explorer is an iOS app that allows users to discover, search, and save their favorite anime. Users can view information about different anime, including posters, ratings, descriptions, and episode counts.

Main Features 

Discover screen 

Display anime from Jikan API 

Search for anime

Anime detail screen

Add anime to favorites

Remove anime from favorites

Favorites screen

Save favorites using UserDefaults
